# 技术：指南针（罗盘）与校准

## 原理与触发条件

飞行器指南针用于感知姿态相对地磁的方位，是保持航向与悬停的基础。
DJI 飞行器在以下情况提示指南针校准（SOURCE-008）：

- App 提示需要指南针校准；
- 飞行器在**磁场或大型金属附近**飞行；
- 飞行器**长时间闲置后重新使用**也可能触发校准提示。

## 干扰源

飞行时/校准时应避开以下强磁场环境（SOURCE-008）：

- 大型电气设备
- 停车场
- 船舶
- 地下钢柱建筑
- 大型金属结构

## 校准方法（DJI Fly）

> 校准前：确保电量至少 **50%**，安装正确 App，飞行器与遥控器已连接。（SOURCE-008）

1. 远离强磁场与大型金属环境。
2. 打开 DJI Fly 飞行界面，进入 `··· > 安全 > 传感器 > 指南针 > 校准`。
3. 按屏幕提示摆放飞行器完成校准（通常为 8 字 / 多方位校准）。
4. 亦可通过带屏遥控器（DJI RC 2 / RC Pro 2）下拉屏幕 → 设置 → Compass Calibration 校准。
5. 校准失败：**重启飞行器或遥控器后再试**；仍失败可申请自助寄修检测。

## 与 RTK / GPS 的区别（售后关键点）

- **指南针问题**：磁场/金属干扰 → 症状为航向漂移、提示校准。
- **GPS/GNSS 问题**：遮挡/电磁干扰导致搜星不足 → 症状为无法定点、水平漂移、进入 ATTI。
- 不要把"停车场/钢筋楼宇导致航向异常"误判为 GPS 或 RTK 问题。

## 人工升级条件

- 空旷环境重复校准仍失败 → 可能存在罗盘硬件故障，建议售后检测。
