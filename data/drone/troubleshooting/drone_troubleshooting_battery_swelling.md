# 故障：电池鼓包 / 开裂

## 适用范围

各类 DJI 智能电池通用（SOURCE-030）。

## 故障现象

- 电池外壳**鼓包、开裂**；
- 或 App 提示电池单体损坏 / 过放。

## 可能原因（官方/保养手册）

- 过放、循环老化、存储保养不当等（SOURCE-030、SOURCE-027）。

## 排查步骤（官方）

1. **立即停止使用**该电池，不要继续充电或飞行。（SOURCE-030）
2. 保修期内 → 通过**自助寄修**申请售后检测。（SOURCE-030）
3. 过保修期 → 建议**购置新电池**，不要自行拆解。（SOURCE-030）
4. 保养手册提示：电池明显鼓包、漏液或损坏 → 停止使用并更换。（SOURCE-027）

## 处理建议

任何鼓包/漏液/损坏一律停用；不充电、不飞行、不拆解（见电池安全文档应急处置）。

## 安全注意事项

- 鼓包/漏液电池有**起火风险**，远离易燃物，勿刺穿。农业电池起火处置参见 T50 安全(SOURCE-036)。

## 人工升级条件

- 疑似鼓包/损坏 → 直接升级人工，引导寄修/换新，勿自助处理。
